# Campus Drinking Water Management System (P16 - The Empty Bottle Problem)

Built with Next.js, React, JavaScript, CSS and MongoDB.

## Setup
1. `npm install`
2. Check `.env.local` has your MongoDB address (default is local MongoDB):
   `MONGODB_URI=mongodb://127.0.0.1:27017/campus_water`
3. `npm run dev`
4. Open http://localhost:3000
5. Open http://localhost:3000/api/seed ONCE to add sample water points.
